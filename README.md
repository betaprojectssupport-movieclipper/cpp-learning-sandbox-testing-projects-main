# My C++ Learning & Practice Projects 🧪

Hey! Welcome to my GitHub. I am nearly 14 (in 5 months) and learning C++ from scratch. This repository is my personal sandbox where I test code out while watching tutorials (like TheCherno's C++ playlist) to figure out how the language works. 

My big goal is to learn enough low-level coding to build my own 3D game engine from scratch and eventually get a job at a studio like Rockstar Games. 

---

## 📁 What's inside these folders:

*   **`/$100GiftCard`** - A quick console script I made to experiment with conditional statements and text output.
*   **`/Crypto Performance Analyzer`** - A terminal tool that takes user inputs and calculates crypto stats like a custom calculator.
*   **`/cheating terminal`** - A fast command-line terminal I built to handle quick math calculations for me.
*   **`/classes testing`** - My practice files for learning Object-Oriented Programming (OOP) and how C++ classes work.
*   **`/destructors`** - An isolated lab file where I was testing explicit object lifetimes and seeing when destructors actually trigger in memory.
*   **`/logger for c++`** - A basic console printing script I put together to practice custom logging formats.
*   **`/testingEnums`** - A project where I was messing around with Enums to see how they map out in code logic.

---

## 🛠️ How I manage this repo:
- **Language:** C++
- **IDE:** Visual Studio
- **Clean Repo:** I intentionally excluded all the annoying Visual Studio project meta-files (`.vs`, `.sln`, `.vcxproj`) so that only my raw `.cpp` and `.h` code files show up here.
