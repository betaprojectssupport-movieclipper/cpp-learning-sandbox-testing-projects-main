# C++ Learning Sandbox & Testing Projects 🧪

Welcome to my central development laboratory! This repository consolidates my historic milestones, console scripts, syntax experiments, and logic prototypes while mastering foundational C++.

---

## 📁 Repository Directory

*   **`/$100GiftCard`** - A text-based console simulator exploring conditional statements and runtime message output.
*   **`/Crypto Performance Analyzer`** - A terminal utility evaluating user-inputted currency configurations and transactional mathematics.
*   **`/cheating terminal`** - A fast CLI engine parsing numeric inputs to execute custom calculations.
*   **`/classes testing`** - Core exercises analyzing object-oriented programming initialization and standard class attributes.
*   **`/destructors`** - Micro-lab testing explicit object lifetimes, dynamic scope terminations, and memory release triggers.
*   **`/logger for c++`** - A basic stream printing tool designed to format console log notifications.
*   **`/testingEnums`** - Implementation tests mapping user logic parameters to C++ enumeration types.

---

## 🛠️ Tooling & Standards
- **Language Standard:** C++
- **Environment:** Visual Studio / MSVC Compiler
- **Source Files:** Only raw source code (`.cpp` and `.h`) is tracked. Visual Studio project meta-files (`.vs`, `.sln`, `.user`) are intentionally excluded to keep the repository lightweight and production-clean.
